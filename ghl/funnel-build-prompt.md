> ## AUTOMATION TRIGGERS FROM FUNNEL
>
> When someone completes Page 3 (checkout), GHL should:
> 1. Create contact with phone number + segment tag
> 2. Add tags: `status:trial`, `segment:[their selection]`, `track:[their selection]`
> 3. Set custom field `subscription_status` = `trial`
> 4. Set custom field `current_day_number` = `0`
> 5. Set custom field `audience_segment` = [their selection]
> 6. Fire webhook → Base44 `inboundSMS` with: `{ "message": "START", "phone": "[phone]", "contactId": "[ghl_id]" }`
> 7. Add to pipeline: **Daily Dose Subscribers** → Stage: Trial
> 8. Send confirmation SMS immediately:
>
> ```
> You're in! ⚖️ Your first Daily Dose of Justice arrives tomorrow morning at 9 AM.
>
> Your subscriber perk: 15% off all Love Law™ apparel.
> Use code SUBSCRIBER15 at shoplovelaw.com/shop
>
> Anytime: text HELP for a list of keywords. Reply STOP to unsubscribe.
> ```
